# D4 Public-Source Research Shortlist

> Research preparation only. These organizations have not been selected as
> pilot partners, contacted, or assigned an outreach owner. This file is not a
> D4 partner list or outreach-execution artifact and does not close `UA-3` or
> `G0-8`.

## Basis

The locked Phase 0 default is a housing-intake pilot with 5-10 high-volume
Kingston providers and 2-3 frontline organizations. This shortlist reduces the
research still needed before the owner chooses a real outreach cohort. It uses
only public organizational channels and existing CareConnect directory records;
it does not infer willingness, capacity, endorsement, or partnership.

## Owner Decision Packet

Before any row is copied into a canonical `D4-YYYYMMDD-partner-list.md`:

1. choose one accountable outreach owner;
2. confirm 5-10 provider organizations and 2-3 frontline organizations;
3. identify a public or privately supplied authorized contact for each target;
4. distinguish primary from fallback targets and avoid duplicate organizations;
5. approve outreach copy and the permitted description of the limited pilot;
6. execute outreach outside this repository and retain dated sent-message,
   meeting, or CRM evidence; and
7. create a non-prep D4 submission only after the outreach log and artifact
   inventory can be completed truthfully.

## Safe Outreach Positioning

Any future outreach should state that CareConnect is an independent,
privacy-first public-interest directory, not a government service or a 211
replacement. It should request feedback or limited pilot participation without
implying endorsement, data-sharing activation, or an existing partnership.
