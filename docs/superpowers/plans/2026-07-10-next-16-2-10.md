# Next.js 16.2.10 Patch Update Implementation Plan

**Goal:** Apply the aligned Next.js 16.2.10 patch family with no unrelated dependency churn or runtime behavior changes.

**Architecture:** Preserve the current package graph and update only the four direct Next packages plus their expected Next-owned transitive lock nodes. Treat any unrelated lock change as a failed update attempt.

**Tech Stack:** npm 10, Next.js 16, ESLint, Vitest, TypeScript.

---

### Task 1: Update the aligned package family

**Files:**

- Modify: `package.json`
- Modify: `package-lock.json`

**Steps:**

1. Update runtime packages `next` and `@next/bundle-analyzer` to `^16.2.10` with scripts disabled.
2. Update dev packages `eslint-config-next` and `@next/eslint-plugin-next` to `^16.2.10` with scripts disabled.
3. Inspect every changed lockfile package and reject unrelated churn.
4. Run `npm ci` with normal lifecycle scripts to prove the lock installs cleanly.

### Task 2: Validate repository compatibility

**Steps:**

1. Run format, lint, type-check, full Vitest, references, and root checks.
2. Run the production build and confirm generated embeddings remain unchanged.
3. Run `npm audit --audit-level=high`.
4. Verify the installed direct package versions are all 16.2.10.

### Task 3: Review and deliver

**Steps:**

1. Obtain an independent package/lock/build evidence review.
2. Address findings and rerun affected checks.
3. Record completed validation in the pull request, then commit, push, and open a focused PR.
